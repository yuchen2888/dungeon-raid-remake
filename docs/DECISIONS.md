# 开发决策

## 2026-10-17：使用实际现有目录

选择当前 dungeon-raid-independent/ 作为唯一接力工作树。实物比 2026-10-16 ZIP 和 Documents 下研究副本更新；不创建历史示例路径、不重新解压覆盖、不移动原资料。上级 sources/ 仍只读。

## 2026-10-17：规则只维护一份

AGENTS.md 是真源，CLAUDE.md / GEMINI.md 用 `@AGENTS.md` 导入。三种启动命令都显式要求检查磁盘状态。不使用模型私有聊天作为项目记忆，也不新建全局 skill/规则。

## 2026-10-17：本地 Git 与逐项准入

原来无仓库，先为原样源码建立基线，再为接力设施做独立提交；本轮使用提交级 `Codex (local relay setup) <codex@local.invalid>` 署名，不修改用户全局 Git 身份。根 .gitignore 默认忽略原版程序/资源及第三方目录，仅允许维护代码和文档。忽略不等于删除，也不等于备份；没有创建远端或上传。未来需用户明确授权后才可创建 GitHub 私有仓库并审阅历史。

## 2026-10-17：单写入者、增量保存

同一目录轮流使用。begin 使用原子 mkdir 锁，冲突就停；显式 recover 只在前一工具停止后使用，先保留现场再转移锁。锁只是协议，各工具必须遵守。checkpoint/handoff 保存暂存、未暂存二进制补丁和非忽略未跟踪文件副本；不自动 stash、stage、commit 或回滚。被忽略资源不复制到断点，继续保留在磁盘。

每个可验证单元做一个小提交，长任务中途也保存。quota 中断后可从真实 diff + 测试恢复，不依赖模型还剩额度写总结。工具额度由各供应商管理，本机制不保证额度检测、自动切换或共享聊天。

## 2026-10-17：隔离构建并保留旧证据

既有测试会就地改写报告及大 fixture；复制必要输入后运行。新结果独立保存并与来源哈希绑定，失败/缺依赖不伪报通过。历史 16 模块文档保留，不将其过时描述覆盖现有 19 模块事实。
